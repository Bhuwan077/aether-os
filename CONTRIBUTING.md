# Contributing to AetherOS

Thank you for your interest in contributing to **AetherOS**! We welcome contributions to our web workstation and cybernetic development suite.

## Development Workflow
1. Fork and clone the repository.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Run the automated test suite: `npm test`
5. Ensure type safety: `npx tsc --noEmit`
6. Build production bundle: `npm run build`

## Code Style
- Write clean, modular, and strongly typed TypeScript.
- Follow functional React patterns and custom hooks.
- Write unit tests for new features and algorithms.
