# Changelog

All notable changes to **AetherOS** are documented in this file.

## [3.2.0] - 2026-09-22 — Cyber-Physical Computing Release
### Added
- **CryptForge**: Classical ciphers (Caesar, ROT13, Atbash, Vigenère, XOR, Reverse), SHA-256 standard with 256-bit avalanche heatmap, RSA arbitrary-precision `BigInt` key generation & encryption, and LSB image steganography.
- **SQLSand**: In-browser relational SQL database engine with pure TypeScript lexer, recursive descent AST parser, and relational execution engine supporting `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `INNER JOIN`, `CREATE TABLE`, and `DROP TABLE`.
- **CelestialOrbits**: 2D N-body gravitational physics sandbox utilizing symplectic Velocity Verlet integration for Keplerian orbital stability, with presets (*Solar System*, *Figure-8*, *Binary Star*, *Lagrange Trojans*, *Chaotic Triple*) and interactive mouse slingshot vector launcher.
- **BeatMatrix**: 16-step drum machine & sequencer utilizing Web Audio procedural synthesis (`playKick`, `playSnare`, `playHiHat`, `playLaser`, synth bass, cyber blip) with BPM clock and rhythmic presets.
- **System Themes**: Added Cyberpunk Amber high-contrast CRT preset.
- **Terminal Commands**: Added `uptime` and `hostname` commands to RetroTerm.
- **Documentation**: Added CONTRIBUTING.md, CODE_OF_CONDUCT.md, and updated master README architecture diagrams.

## [2.5.0] - 2026-09-21 — Quantum & Neural Expansion
### Added
- **NeuralPlayground**: Interactive multi-layer perceptron (MLP) with 2D decision boundary heatmap and synthetic datasets.
- **QuantumStudio**: Multi-qubit statevector simulator with quantum gates and Bell/GHZ presets.
- **ShaderForge**: WebGL audio-reactive GLSL fragment visualizer.
- **CyberPaint**: 8-bit pixel art canvas with timeline animation and PNG export.
- **FileFlow**: Dual-pane graphical file explorer for the Virtual File System.
- **NotificationCenter**: Global floating notification toast system with procedural chime sounds.
- **CosmosWallpaper**: Dynamic canvas wallpaper with interactive particle physics.
- **Inline Calculator**: Spotlight command palette inline math solver.

## [1.0.0] - 2026-09-20 — Genesis Release
### Added
- **WindowManager**: Multi-window glassmorphism compositor with dragging, resizing, snapping, and stacking.
- **Virtual File System**: LocalStorage-persisted Unix hierarchical file system.
- **SoundEngine**: Polyphonic Web Audio synthesizer with sound effects.
- **RetroTerm**: Unix shell with matrix digital rain and autocomplete.
- **AlgoPulse**: Algorithm studio with Sorting, Pathfinding, and Game of Life visualizers.
- **CodeCraft**: In-browser JavaScript code editor and sandbox with performance benchmark.
- **SynthLab**: 2-octave piano keyboard with ADSR envelopes and oscilloscope.
- **MindCanvas**: Force-directed graph knowledge map.
- **TaskNexus**: Kanban board with Pomodoro timer.
- **SysMon**: Real-time CPU/RAM telemetry monitor.
